# BatchBite: notes for AI assistants
 
**Project title:** BatchBite, a preorder and production platform for small food businesses.
 
AI assistants used in this repo (such as Claude) read this file. Team members should read it
too, so everyone knows how AI is used on this project and what is expected from it.

## The project
 
- BatchBite helps home bakers, student food stalls and small kitchens manage limited
  production through advance orders. A baker opens a production batch (for example, 40
  dessert boxes for Thursday), customers order and choose a pickup slot, and the business
  sees confirmed demand.
- Course: SWEN 360 Software Design and Engineering, Project 6, Assignment 01
  (Requirements Analysis and Initial Design).
- Team: Shaheem (Scrum Master, compiles `Design.md`), Ali (UML diagrams and reviewing),
  Saad (user stories in the requirements), Abdulrahman (wireframes and requirements),
  Kishan (wireframes).
- Sprint 1 is a planning and design sprint: requirements, wireframes, architecture and UML
  diagrams.
- The application runs locally. There is no budget, so free tools only.
- The course permits AI tools, provided their use is honest.

## How AI is used in this project
 
Tools used by the team: Claude (chat). 
 
Uses that are fine:
- Explaining concepts and formats (user stories, UML, Kanban, GitHub pull requests).
- Brainstorming ideas, layouts and examples to react to.
- Giving feedback on a member's draft, diagram or wireframe and pointing out gaps.
- Producing first drafts of team documents (for example sections of `Design.md`), which the
  team then checks against the real project and edits.
- Formatting notes that a member supplies.
Uses that are not fine:
- Writing a member's individual role-based section (Section B of the submission). Members
  write these in their own words from their own work.
- Inventing process evidence (see rule 2 below).
- Presenting AI output as a member's own work without review.
